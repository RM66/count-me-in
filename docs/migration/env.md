# Env var inventory (Phase 1.3)

From `grep -rhoE 'os\.(Getenv|LookupEnv)\("[A-Z_0-9]+"' pkg api cmd` plus `pkg/config/config.go` helpers. Required/optional classification per `config.Validate()` (production / `STRICT_ENV=1`).

| Var                          | Read by (Go)                                                                            | Required in production (`config.Validate`)       | Notes                                                                                            |
| ---------------------------- | --------------------------------------------------------------------------------------- | ------------------------------------------------ | ------------------------------------------------------------------------------------------------ |
| `APP_URL`                    | `pkg/queue/qstash.go` (publish destinations), `pkg/jobs/links.go` (deep links)          | **yes**                                          | must be absolute http(s) URL without path/query/fragment/user — malformed value fails cold start |
| `AUTH_SECRET`                | `pkg/auth/session.go` (organizer JWT sign/verify)                                       | **yes**                                          | missing → every organizer write silently anonymous; hence hard startup error                     |
| `POSTGRES_URL`               | `pkg/db/client.go` (lazy pool; panics when missing)                                     | **yes**                                          | healthz reports it in `missingEnv`                                                               |
| `REDIS_URL`                  | `pkg/redis/client.go` (lazy singleton; panics when missing)                             | **yes**                                          | healthz `missingEnv`; `config.RedisConfigured()` gates the redis probe                           |
| `QSTASH_TOKEN`               | `pkg/queue/qstash.go`                                                                   | **yes**                                          | publish without it in production is an error; dev without it → outbox rows `skipped` (terminal)  |
| `QSTASH_CURRENT_SIGNING_KEY` | `pkg/jobs/receiver.go`                                                                  | **yes**                                          | receiver refuses every delivery without it                                                       |
| `QSTASH_NEXT_SIGNING_KEY`    | `pkg/jobs/receiver.go`                                                                  | no (deliberately optional)                       | only consulted during key rotation                                                               |
| `QSTASH_URL`                 | `pkg/queue/qstash.go`                                                                   | no                                               | defaults to the public Upstash endpoint; set for local recording sink (Phase 1.4)                |
| `TELEGRAM_BOT_TOKEN`         | `pkg/auth/telegram.go` (widget HMAC), `pkg/jobs/telegram.go` (sendMessage)              | **yes**                                          | also gates widget validation (500 when not configured)                                           |
| `R2_ACCOUNT_ID`              | `pkg/storage/r2.go`                                                                     | no (media routes error, not panic, when missing) | presign + delete                                                                                 |
| `R2_ACCESS_KEY_ID`           | `pkg/storage/r2.go`                                                                     | no (same)                                        |                                                                                                  |
| `R2_SECRET_ACCESS_KEY`       | `pkg/storage/r2.go`                                                                     | no (same)                                        |                                                                                                  |
| `R2_BUCKET`                  | `pkg/storage/r2.go`                                                                     | no (same)                                        |                                                                                                  |
| `R2_PUBLIC_BASE_URL`         | `pkg/storage/keys.go` (URL ↔ key round-trip)                                            | no (same)                                        |                                                                                                  |
| `NODE_ENV`                   | `pkg/config/config.go` (`IsProduction`)                                                 | no                                               | `production` triggers validation                                                                 |
| `VERCEL_ENV`                 | `pkg/config/config.go` (`IsProduction`)                                                 | no                                               | `production` triggers validation (Vercel sets it)                                                |
| `VERCEL`                     | `pkg/httpx/ratelimit.go` (`ClientIP` trusts `X-Forwarded-For` on Vercel)                | no                                               | `1` on Vercel deployments                                                                        |
| `TRUST_PROXY_HEADERS`        | `pkg/httpx/ratelimit.go`                                                                | no                                               | `1` opts a non-Vercel topology into honoring `X-Forwarded-For`                                   |
| `STRICT_ENV`                 | `pkg/config/config.go`                                                                  | no                                               | `1` opts any non-production environment into full validation                                     |
| `CI`                         | test helpers (`pkg/db` tests fail, not skip, when `CI=true` and `POSTGRES_URL` missing) | no                                               | test-only                                                                                        |

## Validation semantics (`config.Validate`)

- Skipped entirely unless `IsProduction()` (`NODE_ENV` or `VERCEL_ENV` = `production`) or `STRICT_ENV=1`.
- Required set: `AUTH_SECRET`, `POSTGRES_URL`, `REDIS_URL`, `APP_URL`, `QSTASH_TOKEN`, `QSTASH_CURRENT_SIGNING_KEY`, `TELEGRAM_BOT_TOKEN` — error message: `missing required environment variables: <joined>`.
- `APP_URL` shape check: scheme http/https, host non-empty, path empty-or-`/`, no query/fragment/userinfo.
