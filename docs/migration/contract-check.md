# Contract validation design (Phase 1.5)

Implemented in Phase 2.4/3.13, enforced in CI from Phase 4. This note records the design decisions made now, so implementation is mechanical.

## Source of truth

`apps/web/openapi.yaml` — generated from Zod by `bun run generate:openapi`. Python never hand-edits it; Python models are generated _from_ it (datamodel-code-generator, Phase 2.4). The public spec stays the Zod one: the FastAPI app is created with `openapi_url=None, docs_url=None, redoc_url=None`.

## Equivalence check (bidirectional oasdiff)

1. `scripts/export-py-openapi.py` builds the spec from the FastAPI routes using a **test-only factory** that enables `openapi_url` (the production app never serves it) and writes `openapi.py.yaml`.
2. Both directions must pass — bidirectional = equivalence at the breaking level, not just "Python didn't break Go's clients":
   - `oasdiff breaking openapi.yaml openapi.py.yaml --fail-on ERR`
   - `oasdiff breaking openapi.py.yaml openapi.yaml --fail-on ERR`
3. Additionally a pytest (`tests_py/test_route_set.py`) asserts the set of `(method, path)` pairs is identical between the two specs — oasdiff's breaking level deliberately ignores some additions; the route set must match exactly (23 spec operations; `/api/healthz` is outside both specs by design).

## Shared vectors reused unchanged

- `packages/contracts/vectors/validation/*.json` — drive `tests_py/validation/test_validation_vectors.py` (same files the Go `TestValidationVectors` runs).
- `packages/contracts/vectors/domain/*` — drive `tests_py/contracts/test_domain_vectors.py`.
- `pkg/contracts/testdata/golden` — golden samples for the generated models; moved to `tests_py/contracts/golden` in Phase 5 (before `pkg/` deletion) and repointed (`TestGoldenCoverage` → `test_golden_coverage`).

## Drift prevention summary

| Layer              | Go (today)                                          | Python (target)                                                                                       |
| ------------------ | --------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| Spec ↔ router      | oapi-codegen generated mux = compile error on drift | route-set pytest + bidirectional oasdiff in CI                                                        |
| Spec ↔ models      | oapi-codegen `types_gen.go`                         | datamodel-codegen `models_gen.py` (regenerated by `bun run generate:py`; CI fails on stale artifacts) |
| Request validation | kin-openapi vs embedded spec + `pkg/validation`     | Pydantic generated models + `validation/` port, same vectors                                          |
| Constants          | `constants_gen.go`                                  | `constants_gen.py` from the same `generate-constants.ts` run                                          |
| i18n copy          | `translations_gen.go`                               | `translations_gen.py` from the same translations package                                              |
